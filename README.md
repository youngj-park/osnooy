# osnooy

아이의 행복을 위해 모든 것을 하는 회사, **osnooy**의 공식 소개 페이지입니다.

## 구조

```
index.html          # 페이지 본문
assets/styles.css   # 스타일
assets/main.js      # 모바일 메뉴, 스크롤 애니메이션
```

빌드 과정 없는 정적 사이트입니다. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 로컬 미리보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포 (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`
